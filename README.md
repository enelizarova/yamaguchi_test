# Scroll slider prototype

Небольшой тестовый прототип лендинга со слайдами, управляемыми прокруткой страницы.

На десктопе GSAP и ScrollTrigger связывают смену слайдов с прокруткой. Колесо синхронизировано с таймлайном и позволяет перейти к нужному слайду по клику. На мобильных устройствах блоки остаются в обычном потоке страницы без JavaScript-анимации.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка и проверки:

```bash
npm run lint
npm run format:check
npm run build
```
