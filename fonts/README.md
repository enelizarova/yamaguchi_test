# Euclid Circular A

Положите в эту папку лицензированные файлы шрифта:

- `EuclidCircularA-Regular.woff2`
- `EuclidCircularA-Medium.woff2`
- `EuclidCircularA-SemiBold.woff2`
- `EuclidCircularA-Bold.woff2`

Имена уже подключены в `css/fonts.css`. Если файлы называются иначе, обновите пути в объявлениях `@font-face`.
